# Cookery

Hands-free cooking with Codex voice and an iPhone camera overlooking your kitchen. Codex can guide you through a recipe, checking your progress, and showing visual references on your laptop.

## Install

You’ll need a Mac with Codex, an iPhone, and a secure phone mount (masking tape to the ceiling is fine).

Install with an agent:

```text
Install the Cookery plugin from https://github.com/rrwwee/cookery. Add the repository as a plugin marketplace, then install cookery@cookery.
```

Or just run these commands in your terminal:

```sh
codex plugin marketplace add https://github.com/rrwwee/cookery.git
codex plugin add cookery@cookery
```

## Start cooking

1. Mount your iPhone above the kitchen with the hob and preparation area in view, and place your Mac nearby.
2. In a new local Codex chat, use Cookery’s **cook** skill and tell it what you’d like to make.

Use **Codex Voice** to stay hands-free.
